# Asset Management & Allocation Platform

An institutional-grade resource reservation system with role-based privileges, data-integrity safeguards, and a real-time administrative tracking dashboard.

---

## 🛠️ Technology Stack
- **Frontend:** React, Axios, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas via Mongoose ORM
- **Security:** JSON Web Tokens (JWT), Cryptographic Bcrypt Hashing

---
